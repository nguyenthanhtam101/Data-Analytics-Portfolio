# Project Name: Olist E-commerce Customer Segmentation

## 1. Objective (Mục tiêu): Phân loại 100.000 khách hàng để tối ưu hóa chiến dịch Marketing, giải quyết vấn đề khách hàng rời bỏ.

## 2. Tools (Công cụ):

MongoDB: Sử dụng Aggregation Framework ($lookup, $unwind, $group) để làm sạch và hợp nhất dữ liệu lớn.

Excel: Sử dụng hàm thống kê (PERCENTRANK) để tính điểm RFM và Pivot Table để trực quan hóa.

## 3. Key Findings (Kết quả chính):

Vấn đề: Doanh nghiệp phụ thuộc 85% vào khách hàng mới và khách vãng lai (Standard).

Cơ hội: Nhóm khách hàng VIP (Champions) chi tiêu gấp 5 lần trung bình nhưng số lượng đang giảm.


Đề xuất: Chuyển dịch 30% ngân sách quảng cáo sang các chương trình Loyalty để giữ chân nhóm "New Customers".
